# 📘 MiniGuia Python para Dados — NotebookLM

Projeto de estudo desenvolvido com apoio do Google NotebookLM, utilizando engenharia de prompts, curadoria de fontes e Inteligência Artificial para aprofundamento em Python para análise de dados.

---

# 🎯 Contexto e Objetivos

Este repositório apresenta um caderno temático focado no estudo de Python para Dados, explorando ferramentas e conceitos amplamente utilizados no mercado de tecnologia e análise de dados.

O projeto teve como principal objetivo utilizar IA generativa como ferramenta de apoio ao aprendizado técnico, organização do conhecimento e produção de materiais de revisão.

## Objetivos do Projeto

* Explorar o uso do NotebookLM como ferramenta de estudo;
* Desenvolver habilidades em engenharia de prompts;
* Consolidar conteúdos técnicos de Python, Pandas e SQL;
* Criar materiais reutilizáveis para futuras revisões;
* Documentar testes, melhorias e dificuldades encontradas durante o processo de aprendizagem.

# 🤖 Engenharia de Prompts

Durante o desenvolvimento do estudo, diversos prompts foram testados e refinados para melhorar a qualidade das respostas geradas pela IA.

## Prompt 1

```text
Preciso que você atue como meu professor de análise de dados com Python.
```

### Resultado Obtido

* Boa contextualização inicial;
* Explicações mais didáticas;
* Necessidade de aprofundar exemplos reais.

---

## Prompt 2

```text
Quero que você me prepare aulas no estilo do professor João Lira da Hashtag Treinamentos.
```

### Resultado Obtido

* Melhor organização do conteúdo;
* Explicações mais práticas e objetivas;
* Estrutura semelhante a aulas de cursos profissionalizantes.

---

## Prompt 3

```text
Utilize um formato mais explicativo e técnico, sem repetir bordões. A partir dessa atualização, monte módulos de estudo estruturados.
```

### Resultado Obtido

* Melhor equilíbrio entre teoria e prática;
* Conteúdo mais limpo e profissional;
* Respostas mais alinhadas ao objetivo de estudo.

---

# ⚠️ Dificuldades Encontradas ("Cicatrizes")

Durante o processo, algumas dificuldades foram identificadas:

* Prompts genéricos geravam respostas superficiais;
* Necessidade de contextualizar melhor os pedidos;
* Ajustes constantes para obter exemplos mais próximos do mercado;
* Refinamento contínuo para melhorar a profundidade técnica das respostas.

Esses desafios contribuíram para o desenvolvimento de habilidades de troubleshooting e engenharia de prompts.
